# Ícones

Pacote `@phosphor-icons/react`, importado por nome com o sufixo `Icon`
(`import { TrashIcon } from "@phosphor-icons/react"`). O `components.json` também aponta
para ele, então componentes novos adicionados pela CLI já chegam com estes ícones.

## Tamanhos

Quatro tamanhos, pela escala de espaçamento (`size-*`):

<Painel>
	<div className="flex items-end gap-8">
		{[
			["size-3", "12px", "indicador mínimo (check do confirmado)"],
			["size-4", "16px", "padrão: botões, inputs, tabelas"],
			["size-5", "20px", "navegação, sidebar"],
			["size-6", "24px", "estado vazio, destaque de card"],
		].map(([classe, px, uso]) => (
			<div key={classe} className="flex flex-col items-start gap-2">
				<GaugeIcon aria-hidden className={classe} />
				<code className="text-code">{classe}</code>
				<span className="text-small text-text-muted">
					{px} · {uso}
				</span>
			</div>
		))}
	</div>
</Painel>

Dentro do `Button` o ícone já sai com 16px (e com padding ajustado); não passe `size`.

## Peso

<Painel>
	<div className="flex gap-8">
		{["regular", "bold", "fill"].map((peso) => (
			<div key={peso} className="flex flex-col items-start gap-2">
				<div className="flex gap-3">
					<CheckCircleIcon aria-hidden weight={peso} className="size-6" />
					<LightningSlashIcon aria-hidden weight={peso} className="size-6" />
					<HouseIcon aria-hidden weight={peso} className="size-6" />
				</div>
				<code className="text-code">weight="{peso}"</code>
			</div>
		))}
	</div>
</Painel>

- **`regular`** (padrão, não precisa passar): todos os usos comuns.
- **`bold`**: só em 12px, onde o traço regular some (ex.: o check do confirmado).
- **`fill`**: estado ativo/selecionado, como o item atual da navegação.
- `thin`, `light` e `duotone` não são usados: somem no fundo escuro ou competem com o accent.

## Cor

Ícone herda `currentColor`: a cor vem do texto do pai (`text-text-muted`, `text-success`,
`text-on-accent`…). Não use a prop `color`; ela foge dos tokens e não troca com o tema.

<Painel>
	<div className="flex flex-wrap gap-5 text-body">
		<span className="flex items-center gap-1.5 text-success">

			+3,9%

			<WarningIcon aria-hidden className="size-4" />
			Competência incompleta
		</span>
	</div>
</Painel>

## Acessibilidade

- Ícone ao lado de texto é decorativo: `aria-hidden`.
- Botão só com ícone: o nome vai no botão (`<Button size="icon" aria-label="Exportar CSV">`)
  e o ícone continua `aria-hidden`.
- Ícone nunca é o único portador de um estado: delta leva sinal (+/−), status leva texto.
