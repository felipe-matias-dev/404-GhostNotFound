# Estados

Tokens em `src/styles.css`. Os exemplos estão nos dois temas; passe o mouse para ver o hover
real.

## Botões

Componente: `Button` de `#/components/ui/button` (shadcn/ui adaptado aos tokens; story em
**Componentes/Button**).

<Temas empilhado>
	<Botoes />
</Temas>

| Estado       | default                | destructive            | outline / ghost             | secondary                    |
| ------------ | ---------------------- | ---------------------- | --------------------------- | ---------------------------- |
| Repouso      | `accent` + `on-accent` | `danger` + `on-danger` | transparente (outline: `border-strong`) | `surface-2` + `border` |
| Hover        | `accent-hover`         | `danger-hover`         | `hover`                     | borda `border-strong`        |
| Pressionado  | `accent-hover`         | `danger-hover`         | `pressed`                   | borda `border-strong`        |
| Foco         | anel de 3px em `focus-ring` a 50% + borda `focus-ring` (padrão do shadcn) | | | |
| Desabilitado | `surface-2` + `border` + `text-disabled`, em qualquer variante | | | |

- `hover` e `pressed` são camadas translúcidas: funcionam sobre `bg`, `surface-1` ou
  `surface-2` sem um token por superfície. No escuro, `hover` sobre `bg` resulta
  exatamente no `surface-1` (“sobe um degrau”).
- O accent e o danger não usam a camada: têm `accent-hover` e `danger-hover`.
- **Desabilitado não usa opacidade.** Amarelo a 50% sobre grafite vira oliva; por isso todo
  controle desabilitado vira `surface-2` + `text-disabled`. O contraste baixo é proposital
  (a WCAG isenta controles desabilitados).
- No `Button`, desabilitado também tira os eventos de ponteiro (`pointer-events-none`), então
  o hover não aparece. Em controle feito à mão, use `enabled:hover:` e `enabled:active:`.
- Ação destrutiva **irreversível** (excluir carga, revogar acesso): `HoldToConfirm` com
  `tone="destructive"` em vez do `Button` `destructive`. O botão fica neutro em repouso e o
  vermelho só varre a face enquanto o usuário segura (1,8 s); clique solto não faz nada.

## Badges e alertas

<Temas>
	<Badges />
	<div className="h-4" />
	<Alertas />
</Temas>

- Badge e alerta: fundo `*-subtle`, texto na cor semântica (`info`, `success`, `warning`,
  `danger`). Contraste da cor sobre o próprio subtle: 7.6 a 8.1 no escuro, 4.5 a 6.8 no
  claro.
- Destaque de marca usa `accent-subtle` com texto `text`: no claro, `accent-text` sobre
  `accent-subtle` tem 4.47:1.
- Alerta não ganha borda colorida nem sombra; o fundo já separa.
